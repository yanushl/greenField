Validation is intentionally duplicated: client-side for immediate UX feedback, server-side for data integrity regardless of caller.

3 · Security Model

All access is granted via the Lead_Capture_Access permission set. The Apex controller runs with sharing, enforcing record-level sharing rules.

Permission Set grants

Layer Grant
Apex class LeadCaptureController — execute
Lead object Create, Read
Lead object No Edit, Delete, View All
FLS Source_Account__c Read + Write
FLS Capture_Notes__c Read + Write
